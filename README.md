# 绒绒造梦屋 · Fluffy Dream Studio

[打开游戏 / Play now](https://ai8458.github.io/fluffy-dream-studio/)

一个软萌的 Q 版 3D 捏脸换装小游戏。选择脸型、发型、五官、衣服和配饰，创造自己的小可爱。

- 自由捏脸、换装、旋转查看，支持手机和电脑。
- 三套灵感穿搭、随机搭配、撤销和重做。
- 点击名字改名，收藏造型，下载 PNG 纪念照片。
- 无需登录，没有广告或付费，造型只保存在当前浏览器。

使用支持 WebGL 2 的现代浏览器。手机上向下滚动编辑时，娃娃预览会保留在屏幕上方。清除浏览器数据会删除本地收藏，请下载照片备份喜欢的作品。
