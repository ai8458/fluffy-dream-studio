# 绒绒造梦屋 2.0 · Fluffy Dream Studio

[打开游戏 / Play now](https://ai8458.github.io/fluffy-dream-studio/)

一个柔和糖果色的 Q 版 3D 捏脸换装小游戏，支持手机、电脑和键盘操作。

## 自由创作

- 9 种脸型、10 种发型、6 种眼睛和 6 种嘴型，支持脸宽、脸颊、下巴、鼻子、眼睛大小和间距调整。
- 18 套服装、7 种布料图案、5 款鞋子，以及独立的主色和装饰色。
- 8 款脸部彩绘，包括雀斑、星星、爱心、猫咪胡须、蝴蝶、彩虹、樱花和雪花。
- 头饰、眼镜、耳饰、颈饰、手持物和翅膀可同时佩戴。
- 8 种背景、4 个姿势、动态花瓣与泡泡、5 款照片相框。
- 随机搭配、六套灵感穿搭、撤销重做、本地收藏和 PNG 照片下载。

## 灵感旅行

打开 12 封主题邀请，按四个提示设计造型、收集印章与灵感星。完成不同主题可解锁爱心眼镜、蝴蝶翅膀、星河礼服、独角兽角、彩虹庆典和极光背景。旅行手账会保存每一站的完成照片，支持重访和继续打扮。

没有倒计时，也不会评价脸型或肤色。无需账号，没有广告或付费。旧版造型和收藏会保留；全部数据只保存在当前浏览器，清除网站数据会清空收藏与旅行进度。

部分特别装饰需完成主题邀请解锁。使用支持 WebGL 2 的现代浏览器，手机向下滚动编辑时，娃娃预览会留在屏幕上方。
